Javascript Datatypes

Javascript have 8 types of datatypes

1. String

A group of character called string in Normal language we call sentence or words. For string you can use "" or '' quote as shown below


       let string = "Double quotes";
       let strings = 'single quotes';

2. Number

A numbers represent normal mathematical value.


       let number = 1234567890;
       let numbers = 45.5;

3. BigInt

BigInt is used for large number and in the end type n or BigInt()


       let x = 1234567564656943535665n;
       let z = BigInt(43546586567643564365416865)

4. Boolean

A data type representing in True or False.


       let a = true;
       let b = false;

5. Object

It is collection of key-value pairs of data.


       const personDetails = {
        firstName : "Sachin",
        lastName : "Gupta",
        Location : "Internet",
        Profession : "Pharmacist"
       }

6. Undefined

A variable with no assigned value.


      let x;
      let y;

7. Null

A Value representing oject absence


      let x = null;
      let y = null;

8. Symbol

A unique primitive identifier


      const x = symbol();
      const y = symbol();

Javascript toString()

The JavaScript toString() method converts a variable (or a value) to a string.
It is a built-in method for many data types, including numbers, arrays, dates, and objects.

The method is useful for:

Converting data to a readable format for display
Ensuring type compatibility when a string is required
Customizing objects other user interfaces
Customizing objects for debugging

Javascript toLocaleString()

The toLocaleString() method converts a value to a string, using local formatting rules.

The toLocaleString() method is especially useful for formatting numbers, dates, arrays, currencies, and percentages for different countries.

The toLocaleString() Method

The toLocaleString() method is available for many JavaScript datatypes / objects:

  1. Numbers
  2. Dates
  3. Arrays
  4. BigInt

Javascript Type Coercion

Type coercion is the automatic conversion of values from one data type to another.

Type coercion happens when you perform an operation on different data types, and the JavaScript engine tries to make them "fit" together.

String Coercion (+)

If any part of a + operation is a string, JavaScript converts everything to strings and concatenates them. 


       let x = "5" + 2 // x = "52"

Numeric Coercion

Other arithmetic operators (-, *, /, %) and the unary plus (+x) force values into numbers. 


       let x ="5"-2 // x = 3

Loose Equality

This operator performs coercion to find a "common type" before comparing. 


       let x = (5 == "5") // x = true

Converting Strings to Numbers

The global method Number() converts a variable (or a value) into a number.
A numeric string (like "3.14") converts to a number (like 3.14).
An empty string (like "") converts to 0.
A non numeric string (like "John") converts to NaN (Not a Number).

Examples
These will convert:

Number("3.14")
Number(Math.PI)
Number(" ")
Number("")

These will not convert:
Number("99 88")
Number("John")
